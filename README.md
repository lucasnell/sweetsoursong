
# A Song of Sweet and Sour (Nectar)


[![DOI](https://zenodo.org/badge/768350141.svg)](https://zenodo.org/badge/latestdoi/768350141)


This repo contains the R package `sweetsoursong` and the scripts that create
the figures in the manuscript *Regional species coexistence despite local
priority effects: the overlooked role of dispersal–community feedback*.

The package implements a continuous-time Markov chain model of yeast,
bacteria, and pollinators on flowering plants that are coupled through a
regional pollinator pool:

- per-plant transition rates (`flower_rates()`, `reduced_rates()`);
- the reduced model with a vacancy closure for the filling probabilities
  (`vacancy_hazards()`, `y_distribution()`, `joint_distribution()`);
- the closed metacommunity and invasion criteria (`meta_equilibrium()`,
  `inv_y()`, `inv_b()`, `outcome_grid()`);
- the split of bimodal distributions into modes (`decompose_distribution()`);
- Gillespie simulation (`gillespie_reduced()`);
- the deterministic one-plant model (`determ_equilibria()`, `determ_sim()`);
- the full per-plant model, used as an accuracy check (`full_inv_y()`,
  `full_inv_b()`, `full_meta_equilibrium()`).

It is a port of Christopher Klausmeier's Mathematica code. The tests compare
it with reference values from that code (`tests/testthat/fixtures/`,
generated by `claude-checks/r-port/r_port_reference.wl`). Two defaults differ
from the Mathematica code, and both can be switched back:

- Mathematica's `Chop` is off (`options(sweetsoursong.chop = TRUE)` turns it
  on). This changes no result in Figs 2–6.
- `inv_b()` returns the invader's own pollinator output, `E[BP] / eps`
  (`method = "chris"` gives `(N P_R - E[YP]) / eps`). The two equal 1 at the
  same `P_R`.

Version 1.0.0 of this package (tag `v1.0.0`) implements the different model
of the first submission.


# Organization

```
├── _data           cached results and CSV outputs of the scripts (not tracked)
├── _figures        figures made by the scripts (not tracked)
├── _scripts        R scripts for Figs 2-6 and SI Table S1
├── claude-checks   numerical checks; r-port/ has the Mathematica reference
│                   script and comparisons of R with Mathematica and the
│                   manuscript
├── DESCRIPTION
├── LICENSE.md
├── man
├── NAMESPACE
├── R
├── README.md
├── renv.lock
├── sweetsoursong.Rproj
└── tests
```

Run the scripts from the project root, in order:

```bash
Rscript _scripts/01-fig2.R
Rscript _scripts/02-fig3-4.R
Rscript _scripts/03-fig5.R
Rscript _scripts/04-fig6.R
Rscript _scripts/05-si-table-s1.R
```

They make the computed panels of Figs 2–6. Panels 2A and 5A are schematics.


# Replicating the R environment

I used R 4.6.1 (platform: aarch64-apple-darwin23).

This project uses `renv`. From the project directory:

```r
install.packages("renv")
renv::restore()
```

Without `renv`:

```r
pkgs <- c("deSolve@1.42", "Matrix@1.7-6", "ggplot2@4.0.3",
          "patchwork@1.3.2", "jsonlite@2.0.0", "testthat@3.3.2")
install.packages("remotes")
for (p in pkgs) remotes::install_version(sub("@.*", "", p), sub(".*@", "", p))
remotes::install_github("lucasnell/sweetsoursong")
```
